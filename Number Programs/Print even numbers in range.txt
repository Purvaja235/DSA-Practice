Print even numbers in range

1.A =>  Brute Force
           int a = 1;
           int b = 10;
          for(int i = 1; i<= b; i++){
          if(i % 2 == 0){
              System.out.print(i);
          }
          
         }
		Time Complexity => O(n)
        Space Complexity => O(1) 

2.A =>  Better Approach (Jump by 2)
          int a = 1;
          int b = 10;
          for(int i = a; i<= b; i+= 1){
          if(i % 2 == 0){
              System.out.print(i);
          }
          }
        Time Complexity => O(n)
        Space Complexity => O(1)  
		
3.A =>  Most Optimized Approach
          For printing, this is already optimal because you must print every even number.
          TC = O(number of even numbers) ≈ O(n)
          SC = O(1)
