Convert binary to decimal

Problem Statement
Given a binary number, convert it into decimal.
Example:
Binary = 1101
Output = 13

1.A =>  Brute Force Approach (Using String)
        Logic:- Traverse from right to left.
                Multiply each bit by the corresponding power of 2.
                Add the results.
        String binary = "1101";
		int decimal = 0;
		int power = 0;
		
		for(int i = binary.length() - 1;i >= 0; i--){
		    int digit = binary.charAt(i) - '0';
		    decimal += digit * Math.pow(2, power);
		    power++;
		}
		System.out.println(decimal);
        Time Complexity => O(n)
        Space Complexity => O(1)		
		
2.A =>  Better Approach (Without String)
         int binary = 1101;
		int decimal = 0;
		int power = 0;
		
		while(binary > 0){
		    int digit = binary % 10;
		    decimal += digit * Math.pow(2, power);
		    power++;
		    binary = binary / 10;
		}
		System.out.println(decimal);	
        Time Complexity => O(n)
        Space Complexity => O(1)	

3.A =>  Most Optimized Approach (No Math.pow)
         	int binary = 1101;
		int decimal = 0;
		int power = 1;
		
		while(binary > 0){
		    int digit = binary % 10;
		    decimal += digit * power;
		    power *= 2;
		    binary = binary / 10;
		}
		System.out.println(decimal);
        Time Complexity => O(n)
        Space Complexity => O(1)

Q1. Why avoid Math.pow()?

Because:

It returns double.
Slower than multiplication.

Q2. Can binary contain digits other than 0 and 1?

No.

Q3. Built-in Method?
Integer.parseInt("1101", 2)

Output:

13
