Find frequency of digits

Variation 1: Frequency of a Particular Digit
             Problem: n = 122333  target = 2  Output: 2
			 
1.A =>  Brute Force Approach
        Idea: Extract every digit and compare it with the target digit.		
        int n = 122333;
		int target = 3;
		int f = 0;
		while(n > 0){
		    int digit = n % 10;
		    if(digit == target){
		        f++;
		    }
		    n = n / 10;
		}
		System.out.println(f);
        Time Complexity => O(log n)
        Space Complexity => O(1)		

2.A =>  Most Optimized Approach
        This is already the optimal solution.
        You must inspect every digit at least once.		
        Interview Follow-Up
        Can we do better than O(log n)?
        ❌ No.
        Because every digit must be checked.

Variation 2: Frequency of All Digits

1.A =>  Brute Force Approach
        For each digit from 0 to 9, scan the entire number.
         	int n = 12298333;
		for(int i = 0; i <= 9; i++){
		    int temp = n;
		    int count = 0;
		    while(temp > 0){
		        int digit = temp % 10;
		        if(i == digit){
		            count++;
		        }
		        temp = temp / 10;
		    }
		    if(count > 0){
		        System.out.println(i + "<-" + count);
		    }
		}
		Time Complexity => O(d)
        Space Complexity => O(1)
			 
2.A =>  Better/Optimized Approach (Frequency Array)
        Since digits are only 0-9, create an array of size 10.
         int n = 12298333;
		int[] arr = new int[10]; 
		
		while(n > 0){
		    int digit = n % 10;
		    arr[digit]++;
		    n /= 10;
		}
	    for(int i = 0; i <= 9; i++){
	        if(arr[i] > 0){
	            System.out.println(i + "<-" + arr[i]);
	        }
	    }		
		Time Complexity => O(log n)
        Space Complexity => O(1)
