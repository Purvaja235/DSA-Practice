Check Prime Number

1.A =>  Basic Method
          int a = 13;
	      boolean isPrime = true;
	      
	      if(a <= 1){
	          isPrime = false;
	      }
	      for(int i = 2; i < a; i++){
	          if(a % i == 0){
	              isPrime = false;
	          }
	      }
	      
	      if(isPrime){
	          System.out.println("Prime Number");
	      }
	      else {
	          System.out.println("Not Prime");
	      }
		Time Complexity => O(n)
        Space Complexity => O(1)
		
2.A =>  Optimized (Interview Preferred)
        Important Concept
           If a number has a factor greater than √n,
           it must also have a factor smaller than √n.		
	       for(int i = 2; i * i <= a; i++){
	          if(a % i == 0){
	              isPrime = false;
	          }
	      }
	    Time Complexity => O(√n)
        Space Complexity => O(1)  
		
3.A =>  Count Factors
          int a = 14;
	      int count = 0;
	      
	      for(int i = 1; i <= a; i++){
	          if(a % i == 0){
	              count++;
	          }
	      }
	      
	      if(count == 2){
	          System.out.println("Prime");
	      }
	      else {
	          System.out.println("Not");
	      } 		
		Time Complexity => O(n)
        Space Complexity => O(1)
