Check Positive Negative Number

1.A => Using if-else
           if(temp == 0) {
		    System.out.println("Zero");
		 }
		
		   if(temp >= 0) {
		    System.out.println("Positive");
		 }
		 else {
		    System.out.println("Negative");
		 }
        Time Complexity => O(1)
        Space Complexity => O(1)

2.A => Using Ternary Operator
           String s = (a > 0) ? "Positive" : (a < 0) ? "Negative" : "Zero";
	       System.out.println(s);
        Time Complexity => O(1)
        Space Complexity => O(1)

3.A => Using Nested if
          int a = 34;
	      if(a >= 0) {
	          if(a == 0){
	              System.out.println("Zero");
	          }
	          else {
	              System.out.println("Positive");
	          }
	      }
	      else {
	          System.out.println("Negative");
	      }
		Time Complexity => O(1)
        Space Complexity => O(1)
