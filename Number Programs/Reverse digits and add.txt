Reverse digits and add

1.A =>  Brute Force (String)
        Logic:- Convert number to String.
		Reverse the String.
        Convert it back to integer.
        Add with original number.
	    int n = 123;
		String s = String.valueOf(n);
		String rev = "";
		for(int i = s.length() - 1; i >= 0; i--){
		    rev += s.charAt(i);
		}
		int result = Integer.parseInt(rev);
		System.out.println(result + n);
		
	    Time Complexity => O(log n)
        Space Complexity => O(log n)
		
2.A =>  Better Approach (Mathematical)
        	int n = 123;
	    int temp = n;
        int rev = 0;
	    while(n > 0){
	        int digit = n % 10;
	        rev = rev * 10 + digit;
	        n = n / 10;
	   }
	   int result = rev + temp;
	   System.out.println(result);
   	   Time Complexity => O(log n)
       Space Complexity => O(1)
