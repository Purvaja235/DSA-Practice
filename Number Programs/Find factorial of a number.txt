Find factorial of a number

1.A =>  Brute Force / Iterative Solution (Most Common)
            int n = 5;
	     int fact = 1;
	     for(int i = 1; i <= n; i++){
	         fact = fact * i;
	     }
	     System.out.println(fact);
		
        Time Complexity => O(n)
        Space Complexity => O(1)

2.A =>  Recursive Solution

	        if(n == 0 || n == 1){
	            return 1;
	        }
	        return n * factorial(n - 1);
	    }

	        System.out.println(factorial(5));
