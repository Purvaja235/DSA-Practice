1.A =>  BRUTE FORCE (String method)
          	int n = 153;
		String s = String.valueOf(n);
		int power = s.length();
		
		int sum = 0;
		
		for(int i = 0; i < s.length(); i++){
		    int digit = s.charAt(i) - '0';
		    sum += Math.pow(digit, power);
		}
		if(n == sum){
		    System.out.println("Armstrong");
		}
		else {
		    System.out.print("Not");
		}
		
		Time Complexity => O(log n)
        Space Complexity => O(log n)
		
		Time Complexity: O(d) ≈ O(log n), where d is the number of digits.Since the number of digits in n is: d=⌊log 10(n)⌋+1 we can write: O(d)=O(logn)
	​    Space Complexity: O(d) ≈ O(log n), due to the string created from the number.
