Reverse a number

1.A =>  Brute Force Approach (Using String)
          	int n = 457332;
	
	        String s = String.valueOf(n);
	        String rev = "";
	
	        for(int i = s.length() - 1; i >= 0; i--){
	        rev += s.charAt(i);
	        }
	        System.out.println(Integer.parseInt(rev));
        Time Complexity => O(n²)        becoz at each iteration string is creating new string repeatedly so thus  
        Space Complexity => O(1)
		
2.A =>  Optimal Approach (Mathematical Method)
        	int n = 457332;
	        int rev = 0;
	
	        while(n > 0){
	        int digit = n % 10;
	        rev = rev * 10 + digit;
	        n = n / 10;
	      }
	      System.out.print(rev);    
		Time Complexity => O(log n)  or O(d)        The number of digits grows like log n. Each extra digit means multiplying the number by 10. Therefore: digits ≈ log₁₀(n)
        Space Complexity => O(1)

with Nagative number handling 
	int n = -457332;
	
	boolean negative = n < 0;
	n = Math.abs(n);
	
	int rev = 0;
	while(n > 0){
	    int digit = n % 10;
	    rev = rev * 10 + digit;
	    n = n / 10;
	}
	if(negative) {
	     rev = -rev;
	}
	  System.out.println(rev);
	
    Time Complexity => O(log n)	
	Space Complexity => O(1)
