Print multiplication table

1.A =>  Brute Force (Standard)
         int n = 5;
        for(int i = 1; i <= 10; i++){
            int mul = i * n;
            System.out.println(i + " " + n + " " + mul);
        }
		Time Complexity => O(1)
        Space Complexity => O(1)
		
2.A =>  Better Approach (User-defined range)
          int n = 5;
        int k = 20;
        for(int i = 1; i <= k; i++){
            int mul = i * n;
            System.out.println(i + " " + n + " " + mul);
        }
		Time Complexity => O(k)
        Space Complexity => O(1)
		
3.A =>  Most Optimized Approach
        There is no further optimization possible.
        Because if you need to print k lines, you must execute the loop k times.
        Printing itself takes O(k) time.
        So:Best TC = O(k) SC = O(1)
