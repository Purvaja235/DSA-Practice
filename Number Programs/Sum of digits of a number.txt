Sum of digits of a number

1.A =>  Most Optimized Approach (FAANG Preferred)
            int n = 1234;
	         
	         int temp = n;
	         int sum = 0;
	         while(temp > 0){
	             int digit = temp % 10;
	            
	              sum = sum + digit;
	              temp = temp / 10;
	         }
	        System.out.print(sum);
			Time Complexity => O(log n)
            Space Complexity => O(1)

2.A =>  Brute Force (String Approach)
            int n = -1234;
	        n = Math.abs(n);
	         String s = String.valueOf(n);
	         int sum = 0;
	         for(int i = 0; i < s.length(); i++){
	             
	             int res = s.charAt(i) - '0';
	             sum += res;
	         }
	           System.out.print(sum);
			Time Complexity => O(log n)
            Space Complexity => O(log n)
