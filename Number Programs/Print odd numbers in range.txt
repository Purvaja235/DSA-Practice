Print odd numbers in range

1.A =>  Brute Force
         int a = 1;
         int b = 10;
         for(int i = 1; i<= b; i++){
          if(i % 2 != 0){
              System.out.print(i);
          }
        }
	    Time Complexity => O(n)
        Space Complexity => O(1)
		
2.A =>  Better Approach
        Let's directly jump to odd numbers.
         for(int i = 1; i<= b; i+= 2){
          if(i % 2 != 0){
              System.out.print(i);
          }
        }		
		Time Complexity => O(n)
        Space Complexity => O(1)
		
3.A =>  Most Optimized Approach
        For printing odd numbers, the above approach is already the best.
        You cannot do better than this because you must print every odd number.
        Printing itself takes time.So:
        Best TC = O(number of odd numbers) ≈ O(n)
        SC = O(1)
