Find GCD of two numbers

1.A =>  Brute Force
        Logic : Check every number from 1 to min(a, b).
			int a = 12;
		int b = 18;
		int gcd = 1;
		
		for(int i = 1; i <= Math.min(a, b); i++){
		    if(a % i == 0 && b % i == 0){
		        gcd = i;
		    }
		}
		System.out.println(gcd);
		Time Complexity => O(min(a, b)
        Space Complexity => O(1)
		
2.A =>  Better
        Start from min(a,b) and go backwards.
        	int a = 12;
		int b = 18;
		
		for(int i = Math.min(a, b); i >= 1; i--){
		    if(a % i == 0 && b % i == 0){
		        System.out.println(i);
		        break;
		    }
		}
        Time Complexity => O(min(a, b)
        Space Complexity => O(1)

3.A =>  Most Optimized: Euclidean Algorithm
        This is the expected interview answer.
         int a = 12;
		int b = 18;
		
		while(b != 0){
		    int temp = b;
		    b = a % b;
		    a = temp;
		}
		System.out.println(a);
		Time Complexity => O(log(min(a, b)))
        Space Complexity => O(1)
