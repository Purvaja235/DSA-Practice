Count digits in a number

1.A =>  Brute Force (String Method)
        int n = 14;
	     String s = String.valueOf(n);
	     int count = 0;
	     for(int i = 0; i < s.length(); i++){
	        int c = s.charAt(i) -'0';
	        count++;
	     }
	    System.out.println(count);
		Time Complexity => O(log n)
        Space Complexity => O(log n)	

2.A =>  Better (Division Method)
         int n = 14;
	     int count = 0;
	     while(n > 0){
	         int digit = n % 10;
	         count ++;
	         n = n / 10;
	     }
	     System.out.print(count);		
		 Time Complexity => O(log n)
        Space Complexity => O(1)
		
3.A =>  Most Optimized (Mathematical Formula)
          int n = 14;
	     int count = (int)Math.log10(n) + 1;
	     System.out.print(count);
        Time Complexity => O(1)
        Space Complexity => O(1)		 
	    
        "We can also find the digit count in O(1) using (int)Math.log10(n) + 1, but we need special handling for 0."
