Check neon number
A Neon Number is a number whose sum of digits of its square is equal to the number itself.

1.A =>  Brute Force (String)
          Find square.
          Convert square to String.
          Traverse each character and calculate sum.
          Compare with original number.
		 int n = 9;
        int square = n * n;
        
        String s = String.valueOf(square);
        int sum = 0;
        for(int i = 0; i < s.length(); i++){
            sum = sum + s.charAt(i) - '0';
        }
        if(n == sum){
            System.out.println("Neon Number");
        }
        else {
            System.out.println("Not");
        }
         Time Complexity => O(log n)
         Space Complexity => O(log n) 		

2.A =>  Better (Mathematical)
          Find square.
          Extract digits using % 10.
          Add digits.
          Compare with original number
         	int n = 8;
	        int temp = n;
	        int square = n * n;
	        int digit = 0;
	        int sum = 0;
	        while(square > 0){
	         digit = square % 10;
	         System.out.print(digit);
	          sum += digit;
	         square /= 10;
	        }
	         System.out.println("Sum " + sum);
	        if(sum == n){
	          System.out.println("Neon Number");
	        }
	        else {
	          System.out.println("Not");
         	}		  
			Time Complexity => O(log n)
            Space Complexity => O(1)

3.A =>  Most Optimized Approach
             There is no further optimization possible.
             Because to know the sum of digits, we must examine every digit of n².
             So the mathematical approach itself is the optimal solution.
             TC = O(log n)
             SC = O(1)
