Print factors of a number

1.A =>  Brute Force
        Check every number from 1 to n
		int a = 12;
	    for(int i = 1; i <= a; i++){
	        if(a % i == 0){
	            System.out.print(i + " ");
	        }
	    }
		Time Complexity => O(n)
        Space Complexity => O(1)
		
2.A =>  Most Optimized Approach (Using √n)
        Factors always come in pairs.
        int a = 12;
	    for(int i = 1; i * i<= a; i++){
	        if(a % i == 0){
	            System.out.print(i + " ");
	            if(i != a / i){
	            System.out.println(a / i + " ");
	        }
	        }
	        
	    }	
		Time Complexity => O(√n)
        Space Complexity => O(1)
