Count even & odd digits

1.A =>  Brute Force Approach
        Extract each digit using % 10.
		Check: digit % 2 == 0 True → Even digit False → Odd digit
			int n = 123456;
		int temp = n;
		int oddCount = 0;
		int evenCount = 0;
	    while(temp > 0){
	        int rem = temp % 10;
	        if(rem % 2 == 0){
	            evenCount++;
	        }
	        else {
	            oddCount++;
	             }
	            temp = temp / 10;
	       } 
	       System.out.println(evenCount);
	       System.out.println(oddCount);
		Time Complexity => O(log n)
        Space Complexity => O(1)

        There is no better algorithm.You must inspect every digit at least once.
