Find cube of a number

1.A =>  Direct Multiplication (Interview Expected)
	    int n = 3;
		int cube = n * n * n;
		System.out.println(cube);
		Time Complexity => O(1)
        Space Complexity => O(1)
		
2.A =>  Using a Loop (Power Logic)
        int n = 2;
		int cube = 1;
		for(int i = 1; i <= 3; i++){
		    cube = cube * n;
		 
		}
		System.out.println(cube);
		Time Complexity => O(1)
        Space Complexity => O(1)
		
3.A =>  Using Math.pow()
        int n = 2;
		int cube = (int)Math.pow(n, 3);
	    System.out.println(cube);
		Time Complexity => O(1)
        Space Complexity => O(1)
