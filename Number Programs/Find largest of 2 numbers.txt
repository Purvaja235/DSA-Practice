Find largest of 2 numbers

1.A =>  Brute Force (Using if-else)
         int a = 12;
	     int f = 14;
	     if(a > f){
	         System.out.println("12 is large");
	     }
	     else {
	         System.out.println("14 is large");
	     }
		Time Complexity => O(1)
        Space Complexity => O(1)
		
2.A =>  Using Ternary Operator
         int a = 12;
	     int b = 14;
	     String result = (a > b) ? "12 is large" : "14 is large";
	     System.out.println(result);
         Time Complexity => O(1)
        Space Complexity => O(1)
      
3.A =>  Using Math.max()
           int a = 12;
	     int b = 14;
	    int result = Math.max(a, b);
	     System.out.println(result);
		 Time Complexity => O(1)
        Space Complexity => O(1)
