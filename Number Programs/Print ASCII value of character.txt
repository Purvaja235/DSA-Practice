Print ASCII value of character

1.A =>  Brute Force Approach
        In Java, every char is stored internally as an integer (Unicode/ASCII value).
        We can typecast the character to int.
		char ch = 'A';
	     int a = (int)ch;
	     System.out.println(a);
		Time Complexity => O(1)
        Space Complexity => O(1)	
		
2.A =>  Better Approach
        A char automatically converts to int.
		char ch = 'A';
	     int a = ch;
	     System.out.println(a);
		Time Complexity => O(1)
        Space Complexity => O(1)
		
3.A =>  Most Optimized Approach
        You don't even need an extra variable.		
		char ch = 'A';
	    System.out.println((int)ch);
		Time Complexity => O(1)
        Space Complexity => O(1)
