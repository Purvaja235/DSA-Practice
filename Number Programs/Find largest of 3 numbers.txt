Find largest of 3 numbers

1.A =>  Brute Force (if-else)
        int a = 10;
	     int b = 25;
	     int c = 15;
	    if(a > b){
	        System.out.println("a" + a);
	    }
	    else if(b > c){
	        System.out.println("b" + b);
	    }
	    else {
	        System.out.println("c" + c);
	    }
		Time Complexity => O(1)
        Space Complexity => O(1)

2.A =>  Using Nested Math.max()
        int a = 10;
	     int b = 25;
	     int c = 15;
	     int result = Math.max(a, Math.max(b , c));
	     System.out.println(result);
		Time Complexity => O(1)
        Space Complexity => O(1)

3.A =>  Store Current Largest
         int a = -10;
	     int b = -3;
	     int c = -45;
	     int largest = a;
	     
	     if(b > largest){
	         largest = b;
	     }
	     if(c > largest){
	         largest = c;
	     }
	     System.out.println(largest);		 
		Time Complexity => O(1)
        Space Complexity => O(1)
