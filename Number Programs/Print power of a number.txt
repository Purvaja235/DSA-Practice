Print power of a number

1.A =>  Brute Force (Loop)
        int base = 2;
        int power = 5;
        int result = 1;
        for(int i = 1; i <= power; i++){
            result = base * result;
        }
        System.out.println(result);
		Time Complexity => O(power)
        Space Complexity => O(1)
		
2.A =>  Better Approach (Using Math.pow)
        int base = 2;
        int power = 5;
        int result = (int)Math.pow(base, power);
        System.out.println(result);		
		Time Complexity => O(log power)
        Space Complexity => O(1)
		
3.A =>  Most Optimized Approach (Binary Exponentiation)
         int base = 3;
        int power = 5;
        int result = 1;
        while(power > 0){
            if(power % 2 == 1){
                result = result * base;
            }
            base = base * base;
            power = power / 2;
        }
        System.out.println(result);	
        Time Complexity => O(log power)
        Space Complexity => O(1)
